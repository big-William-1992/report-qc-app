# 授权与激活说明（Activation & Licensing）

本软件采用「**免责声明 → 免费试用 → 激活码**」三层授权模型，
所有授权逻辑在 `src/license_utils.py`，发卡工具在 `gen_activation_gui.py` 与 `web_issuer/server.py`。
本文档同时面向**终端用户**（如何激活）与**开发者 / 运营**（如何发卡、如何保管私钥）。

---

## 1. 三层授权模型

| 层级 | 触发时机 | 行为 |
| --- | --- | --- |
| ① 免责声明 | 首次运行 | 弹「用户协议与免责声明」，同意写入 `assets/license.dat`，后续不再弹 |
| ② 免费试用 | 首次运行起 90 天 | `TRIAL_DAYS = 90`，到期前显示剩余天数；到期后提示激活 |
| ③ 激活码 | 试用到期后 | 输入有效激活码方可继续使用；激活状态写入 `license.dat` |

> 合规定位：本软件为「科研 / 教学辅助」工具，授权与激活**不构成医疗诊断闭环**。
> 免责声明已内置，用户须同意方可使用；质控结果仅供参考，最终由放射科医师确认。

## 2. 激活码原理（Ed25519 非对称验签）

- **非对称**：开发者持有**私钥** `keys/private_key.pem`，对客户机器的「硬件识别码」签名生成激活码；
  客户端**仅内置公钥**（硬编码于 `license_utils._PUBLIC_KEY_PEM`），用于验签。
- **机器绑定**：激活码与某台机器的硬件标识（`_stable_hw_id()`）绑定——
  Windows 用 `MachineGuid`、macOS 用硬件 UUID、Linux 用 `/etc/machine-id`、兜底为 `hostname`。
  重装系统 / 换网卡尽量不变；**换机通常需重新发卡**。
- **抗伪造**：客户端无私钥，无法自行生成有效激活码；仅持有公钥无法反推私钥。

## 3. 终端用户：如何拿到并填入激活码

1. 试用期结束 → 弹「软件激活」框，显示：
   `机器识别码（发卡用）：<一串字符>`
2. **完整复制**该机器识别码，发给开发者（客服 / 你）。
3. 开发者用下方任一方式生成激活码并回发。
4. 在激活框粘贴激活码 → 点「激活」→ 显示「激活成功」。

> 提示：激活码与机器绑定，请勿跨机器使用；换机 / 系统重置后需重新向开发者申请。

## 4. 开发者：如何发卡（两种方式）

### 4.1 GUI 发卡工具（推荐，离线）

```bash
python3 gen_activation_gui.py
```

- 粘贴客户机器识别码 → 点「生成激活码」→ 点「一键复制激活码」发给客户。
- 前提：本机需 `keys/private_key.pem`（**切勿提交仓库 / 随分发包**）。
- 私钥缺失会明确报错，不会静默生成无效码。

### 4.2 Web 发卡原型（演示 / 内测）

```bash
python3 web_issuer/server.py
# 浏览器访问 http://localhost:8777
```

- 提交机器码 → 「模拟支付」→ 返回激活码（前端永不接触私钥）。
- ⚠️ **当前为本地演示原型**，生产前必须补齐：
  ① 真实支付回调（当前「点击即视为已付款」）；
  ② 私钥放密钥管理服务而非本地明文文件；
  ③ 限频 / 防滥用 / 订单持久化（当前订单仅存内存，重启清空）。

## 5. 内测 / 早期分发建议（当前阶段）

当前处于**内测与功能验证期**，可暂不启用严格付费：

- 直接让内测用户走 90 天免费试用；
- 或由你用 **GUI 发卡工具**手动免费生成激活码，发给放射科同行，
  便于在真实场景下收集误报 / 漏报，把「功能分」转化为「可信分」。

待**公司注册、付费通道与正式签名**就绪后，再切换为「付费即发卡」的生产流程
（届时 `web_issuer` 需升级为带支付回调与密钥管理的正式发卡拉务）。

## 6. 私钥安全（必读）

- `keys/private_key.pem` 是**唯一**可签发激活码的凭证，
  **绝不入库（`.gitignore`）、绝不进分发包、绝不外泄**。
- 一旦泄露：攻击者可伪造任意机器激活码。须**立即轮换密钥对**
  （重新生成公私钥，并更新 `license_utils._PUBLIC_KEY_PEM` 内置公钥），旧激活码作废。
- 建议：内测期放本机隔离目录；正式期使用密钥管理服务（KMS / 环境变量注入）。

## 7. 常见问题

| 问题 | 说明 |
| --- | --- |
| 试用期怎么算？ | 首次成功运行记录日期，90 天内免费；过期弹激活框 |
| 激活码能多人用吗？ | 不能，绑定单机硬件标识 |
| 重装系统要重新激活吗？ | 大概率需要（硬件标识可能变化），重新向开发者申请即可 |
| 忘记激活码？ | 重新用同一机器识别码发卡，激活码可重复生成（确定性签名） |
| 私钥丢了？ | 无法再为旧机器发卡；需轮换密钥对并重新给所有用户发卡 |
