## 一、软件定位

医学影像报告质控系统（以下简称"本软件"）是一款面向放射科的报告**质量辅助核查工具**，
通过确定性规则引擎（规则编号 R1–R25，当前启用 18 类）+ 放射术语/解剖词表
（+ 可选的本地 LLM 语义层），对影像报告正文做自动化质量检查，并沉淀科室质控台账。

**监管状态（事实陈述）**：本软件**尚未取得医疗器械注册证**，**尚未完成网络安全等级保护测评**。
是否按现行《医疗器械分类目录》构成第二类医疗器械、以及对外应如何定性，
**需专业机构确认**（待决项见 [OPEN_DECISIONS.md](OPEN_DECISIONS.md) D1）。
在法定性完成前，请勿对外宣称"已注册""已通过等保"或用于诊断用途。

## 二、重要免责条款

1. **非医疗器械**：本软件不属于医疗器械，未经国家药品监督管理局注册，
   不得用于临床诊断、治疗决策或任何受监管的医疗行为。

2. **不替代医师判断**：质控结果仅供放射科医师参考，最终报告的准确性与合规性
   **以执业医师审核为准**。因依赖本软件输出而产生的任何后果，作者不承担法律责任。

3. **数据本地化**：报告文本、样本库、规则配置等**默认仅存储于使用者本机或院内内网**，
   默认配置下不上传到院外。**但并非"完全离线"**，以下情形会产生网络行为，使用者须知情：
   - **RIS/PACS 直连**（由使用者配置）：与院内系统通信（轮询或接收推送）；
   - **浮动授权**：读写院内共享目录的心跳文件以统计座位；
   - **自动更新**：检查/下载更新包（可关闭或改用离线通道）；
   - **云端 LLM（可选）**：仅在显式配置云端接口时启用，届时**报告正文可能外发**；
     默认使用本地模型。
   使用者应自行妥善保管含患者信息的本地数据，遵守所在机构的隐私与数据安全规定。

4. **使用风险自担**：本软件按"现状"提供，不保证无缺陷、无中断、结果完全准确。
   使用者须结合自身专业判断使用，风险由使用者自行承担。
