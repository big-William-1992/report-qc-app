## 二、本轮新发现（漏报猎杀，按严重度排序）

### 🔴 P1 — R5 完全依赖 NER 解剖实体，NER 漏标器官即整体失明
- **现象**：`检查所见：肝实质内见占位性病变。\n诊断印象：请结合临床。` → 仅触发 R19-HOMOPHONE，**不报 R5-CONSISTENCY**。
- **根因**：`_r5_consistency` 仅遍历 `ents` 中 `label=="anatomy"` 的实体。实测上述输入 NER 只抽出 `占位`(sign)，**未把"肝"识别为 anatomy 实体** → `fam_mk` 为空 → R5 完全看不到器官，自然不报。
- **为何致命**：对质控产品，**漏报（真实错误没抓到）比误报更危险**。凡是 NER 漏标器官的报告（器官词未被识别），R5 一律失效——即便"描述明确阳性 + 结论毫无对应"这种最该抓的错误也漏掉。
- **复验**：即便写"肝脏内见占位"（更规范），R5 仍不触发（NER 仍未标肝）→ 非偶发，是系统性 NER 依赖盲点。
- **修复方案**：给 R5 增加**文本级器官兜底**——仿 R2 分支2，对 `ANATOMY_SYNONYMS` 中已知器官词做文本扫描：若描述段某器官词附近存在阳性标记（POSITIVE_MARKERS），且结论段未就该器官给结论，则报 R5。不纯靠 NER。

### 🟠 P2 — R2 文本级器官映射缺"肾"等，游离文本侧别矛盾漏报
- **现象**：`检查所见：左侧肾脏见结石。\n诊断印象：右侧肾脏结石。` → **不报 R2-LATERALITY**（空结果）。
- **根因**：R2 分支2 遍历 `ORGAN_SIDE_LIST`，但用 `zh_organ_to_fam.get(o)` 取器官族；`zh_organ_to_fam` 当前覆盖 **肺/肾上腺/卵巢/睾丸/附件/股骨/肱骨/甲状腺/乳腺/腮腺/膝/髋/肩/肝/输卵管/精囊/锁骨/肋骨**，**不含"肾"**。同时 NER 未把"左侧肾脏"规范为 `L-kidney` → 分支1 也漏 → 两侧矛盾整体漏抓。
- **对比**：写"左肾上极见结石 / 右肾上极结石"（NER 能规范为 L-/R-kidney）时 R2 正常触发 → 盲点仅在"NER 未侧别规范化 + 文本映射缺失"的组合。
- **修复方案**：补全 `zh_organ_to_fam`（至少补 肾/胰/脾 等单字高危器官），或将侧别判定统一改为"器官词表 + 左右前缀"扫描，避免映射表维护遗漏。

### 🟡 P3 — R3 modality 归一化缺口，"乳腺X线"不触发评分缺失
- **现象**：`modality="乳腺X线"` 时 R3 不报；`modality="乳腺"` 或 `"钼靶"` 时正常报 R3-SCORE。
- **根因**：`kg.required_score_for_modality("乳腺X线")→None`（内置映射只有 `乳腺→BI-RADS`、`钼靶→BI-RADS`）。真实 PACS/登记常写"乳腺X线""乳腺钼靶"等，**未归一**导致乳腺报告无 BI-RADS 不告警。
- **澄清**：配置 `rules_config.score_required` 为 `null` 不影响 R3——R3 实际读 KG 内置映射，非该配置键；R3 未被禁用，仅是 modality 字符串归一缺口。
- **修复方案**：在 `required_score_for_modality` 入参前做归一（去 `X线/CT/MR/超声` 后缀、统一小写、扩展别名表）。

## 三、设计层面的增强机会（非 bug，需产品决策）

### 🟡 P3 — R22 不查"病灶漏报尺寸"
- 当前 R22 仅查**术语矛盾**（结节测量>3cm 应称肿块 / 肿块<1cm 应称结节）与**单位误写**（>10cm 疑 mm 误写）。
- `右肺上叶见一结节，边界清。`（无任何尺寸）→ **不报 R22**。是否要新增"病灶必须带尺寸"属产品决策（部分机构质控要求病灶必报长径）。建议作为可配置项，默认关。

### 🟡 P3 — R15-3 "先见后无"要求跨句，同句不抓
- `检查所见：右肺上叶见结节，原病灶已吸收。`（同句）→ R15-PRESENCE **不报**（规则要求 `absn > pres`，即阴性句须在阳性句之后）。
- 真实报告常把"原病灶已吸收"写在同句或同段。建议放宽：同句内若先见阳性词、后出现消失/吸收类词，亦判矛盾。
