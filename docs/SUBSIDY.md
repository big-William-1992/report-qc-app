# 成都/德阳 医疗器械与高企政策补贴地图

> 调研日期: 2026-08-25 | 用途: 报告质控软件(SaMD)商业化路径规划
> ⚠️ 政策有时效性, 申报前务必通过官方渠道二次确认

## 一、省级政策（力度最大, 时效最新）

### 《四川省支持生物医药和医疗器械产业高质量发展若干政策措施》(2025.12, 21条)

| 条款 | 内容 |
|------|------|
| 创新器械补助 | 获批国省级创新医疗器械 → 研发投入 **30%, 最高 200 万** |
| 审评提速 | 二类器械技术审评压缩至 **35 个工作日** |
| 进院支持 | 新优药械目录随时申报及时挂网; 创新药械**不纳入**公立医院绩效考核 |
| AI 定向 | "对脑机接口、核医疗、**人工智能**…定向支持"; 一项目一专班 |

### 省药监局《优化全生命周期监管服务十七条》(2026.8)

- 重点二类审评时限进一步压至 **30 个工作日**
- 预审查 + 优先审评加速通道
- 医学 AI 属定向支持领域, 可申请"一项目一专班"服务

## 二、成都市

### 市级《促进生物医药产业高质量发展若干政策措施》(2025.2~2028.2)

- 二类器械纳入省创新/优先审批程序并首次取证 → **研发投入 10%, 最高 200 万**
- 三类 → 研发投入 20% 最高 500 万

### 成都未来医学城·东部新区 (2025.5 施行) —— 初创首选

```
├─ 首次取得二类注册证:        30万/个
├─ 临床前研究:   检验检测费50%, 最高50万
├─ 临床评价:     试验费40%,    最高20万
├─ 科创空间:     3000㎡ 前3年租金全免, 4-5年减半
├─ 东创贷:       初创企业最高500万授信
├─ 销售奖励:     年销售额破1000万 → 3%/年, 连续3年
└─ 重点赛道白名单明确包含「医学AI+」
```

### 高新技术企业 ("免申即享"——无需申报直接打款)

- 市级首次认定 **10 万**(2025 年已兑付 4462 家/3.58 亿, 最快 1 天到账)
- 区级叠加: 经开区非规上 20 万; 温江区案例 +20 万
- 所得税 25%→15%; 申报窗口每年 3/5/7/9 月四批

## 四、组合测算（二类证路线 · 未来医学城落地示例）

```
支出                          补贴回血
────────────                ─────────────
临床前检测  ~15万    ←      临床前补助   ≤50万
临床评价    ~40万    ←      临床评价补助 ≤20万
体系咨询    ~20万    ←      取证奖励     30万
官费杂项     ~3万    ←      市级研发奖   投入10%(≤200万)
────────────                ─────────────
支出 ~78万                   回血 ≥100万 + 租金全免 + 500万授信额度
```

另叠高企(10~30万)后, 净现金流大概率转正。

## 五、【重磅】成都市人工智能产业政策 (成办规〔2025〕6号, 2025.9.18 施行)
