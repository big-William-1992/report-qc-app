# UIA 真机验证 + 录屏清单

> 目的：在 Windows 真机上确认「PACS 报告能被 UIA 完整读取（无滚动漂移）」，
> 并把验证过程录成短视频用于抖音 / B 站自媒体验证与获客。
> 配套脚本：`tools/uia_selfcheck.py`（命令行版「🔎 UIA检测」+ 证据留存）。

---

## 0. 一句话原理（录屏时可用作口播）

> OCR 是「看像素」——报告一滚动，框里的字就错位。
> UIA 是「读控件」——Windows 把报告文本框存在控件内存里，和滚动、分辨率、字号无关，
> 哪怕报告下半截在屏幕外，也能一次读全。这就是根治滚动漂移的关键。

## 1. 准备

### 1.1 硬件 / 系统
- [ ] 一台 **Windows** 电脑（UIA 仅在 Windows 生效；macOS/Linux 无法调用 UI Automation）。
- [ ] 安装好的**原生 PACS 工作站客户端**（联影 / 东软 / 飞利浦 / GE 等用标准 Win32/WPF/.NET 控件者优先）。
- [ ] 一份**含滚动内容**的真实报告（越长越好，能直观体现「无需滚动读全」）。

### 1.2 软件依赖
- [ ] Python 3.10+（与本软件一致）。
- [ ] `comtypes`（或 `pywinauto`）：
  ```bat
  pip install comtypes
  ```
- [ ] 本软件已按 `docs/INSTALL.md` 装好并能启动 GUI。

### 1.3 录屏工具（任选）
- [ ] **OBS Studio**（推荐，免费，可录屏 + 加画中画 + 字幕）。
- [ ] 或 Windows 自带 **Xbox Game Bar**（`Win+G`，轻量）。
- [ ] 备选：Bandicam / 迅捷录屏。

### 1.4 合规脱敏（必做，录屏前）
- [ ] 报告含患者姓名 / 影像号 / 住院号 → **必须打码**（OBS 加模糊马赛克或后期剪辑遮挡）。
- [ ] 口播与字幕统一口径：**「科研 / 教学辅助工具，非医疗器械，不替代医师诊断」**。
- [ ] 不展示院内网络结构、不触网抓端口——UIA 只读焦点窗口文本，符合数据不出域。

## 3. 真机验证步骤（也是录屏主流程）

> 顺序即分镜顺序。每步在 OBS 里切到对应窗口。

### 步骤 A — 环境自检（10 秒）
- [ ] 打开命令行，运行：
  ```bat
  python tools/uia_selfcheck.py
  ```
- [ ] 确认打印「✅ UIA 运行时可用」。若报缺 comtypes → 先 `pip install comtypes`。
- [ ] （录屏可展示这一步，证明环境 OK。）

### 步骤 B — 聚焦 PACS 报告窗口
- [ ] 点一下 PACS 报告窗口使其置顶（成为「前景窗口」）。
- [ ] 口播：「现在这份报告在屏幕下半截还有内容，但我们先不滚动。」

### 步骤 C — 跑「🔎 UIA检测」（诊断探针）
- [ ] 在软件 GUI 点 **「🔎 UIA检测」** 按钮（= `diagnose_foreground()`）。
- [ ] 弹窗列出前景窗口找到的文本控件（Document / Edit / Text）。
- [ ] 确认列表里出现**报告正文文本**（而非只有按钮/菜单）→ 说明该 PACS 是标准文本控件，UIA 可用。
- [ ] 对照命令行版：`tools/uia_selfcheck.py` 的 ② 诊断输出同源。

### 步骤 D — 主采集读全文（核心卖点）
- [ ] 点软件「主采集（UIA）」。软件读取全文 → 自动回填患者姓名/性别/年龄/部位/侧别 → 切分所见/印象 → 跑 R1–R15 质控。
- [ ] 状态栏出现「已从 PACS 窗口读取并质控（UIA，无滚动漂移）」。
- [ ] **关键镜头**：全程未滚动窗口，却拿到了完整报告（含屏幕外下半截）。

### 步骤 E — 无漂移对照（强化说服力）
- [ ] 同窗口再用一次**旧 OCR 方案**（或演示「滚动后 OCR 错位」的历史问题）做对比：
  - OCR：滚动后识别区域偏移、下半截漏读 / 错位。
  - UIA：一次读全、零偏移。
- [ ] 口播点题：「这就是我们根治滚动漂移的方式。」

### 步骤 F — 证据留存
- [ ] 运行 `tools/uia_selfcheck.py` 后按提示输入 `y` 确认无漂移，脚本在 `uia_evidence/` 生成 JSON+MD 证据。
- [ ] 该证据文件可随视频发布或在文档中引用，证明「非口头声称」。

## 4. 验证通过判定标准

全部满足即视为「UIA 真机验证通过」：
- [ ] `is_available()` 为 True（comtypes 已加载）。
- [ ] `list_text_controls()` 返回 ≥1 个含报告正文的文本控件。
- [ ] `capture_text()` 返回的文本**包含报告开头（检查所见）与结尾（诊断印象/签名）**。
- [ ] 上述过程**无需滚动窗口**即可获得完整内容（无漂移确认 = y）。

任一项不满足 → 视为该 PACS 报告区可能非标准文本控件，见第 5 节降级。

---

## 5. 失败 / 降级预案

若某 PACS 报告显示「未找到文本控件」或读到的内容缺失：
- [ ] **自绘 canvas / OpenGL / DirectX 渲染**：UIA 读不到文本（高端三维后处理工作站常见）。
  → 软件会自动安全返回 None，GUI 提示改用 **OCR / 剪贴板 / DICOM SR**。
- [ ] **焦点不对**：确认点过 PACS 报告窗口使其置顶，再点一次「🔎 UIA检测」。
- [ ] **缺依赖**：`pip install comtypes` 后重启软件。
- [ ] 录屏时如实标注：「该工作站为自绘渲染，UIA 不适用，已切换 OCR」——诚实比完美更重要，反而增信。

## 6. 录屏分镜脚本（抖音 / B 站，约 60–90 秒）

| 时间 | 画面 | 口播要点 |
|---|---|---|
| 0–10s | 标题 + PACS 报告窗口 | 「放射科老被 OCR 滚动漂移坑？今天用 UIA 根治它。」 |
| 10–25s | 命令行跑 selfcheck / 点「🔎 UIA检测」 | 「UIA 读的是控件内存里的文本，不是屏幕像素。」 |
| 25–45s | 点主采集，不滚动读全报告 + 质控结果 | 「不滚动，一次读全，状态栏显示『无滚动漂移』。」 |
| 45–65s | OCR 对照（滚动错位 vs UIA 读全） | 「左边 OCR 滚动就偏，右边 UIA 稳如老狗。」 |
| 65–90s | 合规字幕 + CTA | 「科研教学辅助、非医疗器械；想内测的同行评论区扣 1。」 |

剪辑要点：
- [ ] 患者隐私字段全程马赛克。
- [ ] 结尾固定合规字幕 3 秒以上。
- [ ] 标题带关键词：放射科 / PACS / OCR 漂移 / UIA / 质控。
