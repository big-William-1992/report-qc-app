医学影像报告质控系统

面向放射科医生的报告智能质控助手：粘贴即查、复制即控、自动修正、样本沉淀、科室报表。所有数据仅在本机运行，不上传任何网络。

⬇ 下载 Windows 版 ⬇ 下载 macOS 版 GitHub 仓库

核心功能

覆盖 R1–R10 十大类报告问题，从粘贴到出科报表一站式完成。

🔍

实时剪贴板监听

复制即质控，命中问题弹窗提醒，听写误写及时拦截。监听循环自愈合，不静默中断。

📝

R1–R10 规则引擎

性别矛盾、左右混淆、评分缺失、单位错误、描述-结论矛盾、部位不符、错别字、互斥冲突、模板合规。

✏️

自动修正预览

同音错别字逐条确认后再回填；矛盾类问题只提示不改写，避免误判污染正式报告。

📊

样本库与驾驶舱

错误沉淀、趋势统计，一键导出科室质控报表（CSV），直接用于月度 QA 汇报。

⚙️

可配置规则

错别字词典、互斥冲突、忽略名单、模板规范均可维护，修改即时生效。

🔗

RIS 直连（可选）

院内内网连接 PACS/RIS，批量拉取报告质控入库，配置仅存本机。

软件界面

三页签结构：报告质控 · 质控驾驶舱 · RIS 直连。
