# ===== 医学影像报告质控 · R1–R7 全错误测试用例 =====
# 用途：验证第一代质控引擎对 7 类确定性错误的检出能力。
# 配套元信息（在软件"报告质控"页元信息区填写，或用脚本传入）：
#   性别=男   年龄=58   检查部位=乳腺   申请部位=胸部
#
# 各错误点嵌入位置（报告正文）：
#   R1 性别矛盾  → 元信息性别=男，正文却出现女性专属器官「子宫」(+「乳腺」)
#   R2 左右侧混淆→ 描述段写「左肾」，诊断印象段写「右肾」（同一肾脏部位族方位互斥）
#   R3 评分缺失  → 检查部位=乳腺，但全文未出现 BI-RADS
#   R4 单位错误  → 「18 cmH2O」（cmH2O 非标准医学单位）
#   R5 描述-结论矛盾 → 描述段「左肺上叶」提示占位，印象段未就该器官给结论
#   R6 登记部位不符→ 申请部位=胸部，报告正文主体为「脑实质」(head)
#   R7 描述内部矛盾→ 描述段同时出现男女专属器官「子宫」与「前列腺」
# ===================================================
患者信息：男，58岁。检查部位：乳腺。申请部位：胸部。
检查所见：双侧脑实质对称，左肾见一占位灶，范围约 2.5 cm；左肺上叶另见一占位灶。宫腔压力下测值 18 cmH2O。子宫形态饱满，前列腺体积增大。
诊断印象：右肾占位，考虑恶性可能；建议结合临床随访。
